# Start Here

Welcome to **Engineering Playbook (EP)**.

If you're new to this repository, this guide will help you choose the right learning path based on your current experience and goals.

---

# What is EP?

Engineering Playbook is an open-source knowledge base that helps developers:

- Learn modern frontend engineering
- Build production-ready applications
- Understand software architecture
- Prepare for technical interviews
- Grow from Beginner to Lead Engineer

This repository focuses on **understanding concepts**, **real-world implementation**, and **engineering best practices**.

# Choose Your Learning Path

## Beginner

Recommended order (long-term):

1. Fundamentals
2. JavaScript
3. TypeScript
4. Git
5. React
6. REST APIs
7. Testing

**Today:** start with [React Fundamentals](docs/02-frontend/01-react/01-react-fundamentals/README.md) if you already know basic JavaScript, or use the [JS Interview Core Concepts](interview/javascript/01-core-concepts/README.md) track to strengthen JS while Fundamentals are built out.

---

## Preparing for Interviews

Recommended order (long-term):

1. JavaScript
2. TypeScript
3. React
4. Authentication
5. System Design
6. Testing
7. Production Scenarios

**Today:** [JavaScript Interview Handbook](interview/javascript/README.md) → then React learn modules above.

---

## Senior / Lead Engineers

Recommended order (long-term):

1. Architecture
2. Performance
3. Security
4. Cloud & DevOps
5. Leadership
6. Production Debugging

**Today:** these stages are planned. Use detailed paths in [docs/00-LEARNING_PATHS.md](docs/00-LEARNING_PATHS.md) as the target map.
