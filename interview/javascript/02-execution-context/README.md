# Overview

Execution Context is one of the most fundamental concepts in JavaScript and forms the foundation for understanding how JavaScript code is executed.

Every JavaScript program runs inside one or more execution contexts. Understanding how these contexts are created, managed, and destroyed is essential for mastering concepts such as Scope, Hoisting, Closures, the `this` keyword, and the Event Loop.

This module explains how JavaScript prepares code before execution, manages variables and functions, maintains the Call Stack, and executes code step by step.

Execution Context is one of the most frequently asked JavaScript interview topics across frontend, full-stack, and backend roles.
