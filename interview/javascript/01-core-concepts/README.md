# Overview

JavaScript Core Concepts form the foundation of the language and are among the most frequently asked topics in frontend, full-stack, and JavaScript interviews.

This module covers everything from basic language fundamentals to advanced runtime concepts, including JavaScript engines, memory management, type system, runtime internals, and real-world interview scenarios.

Whether you're preparing for your first frontend interview or a senior engineering role, mastering these concepts is essential before moving on to topics like Execution Context, Scope, Closures, and the Event Loop.

---

# Why This Topic Matters

Most JavaScript interview questions build upon the concepts covered in this module.

A strong understanding of these fundamentals will help you answer questions related to:

- Execution Context
- Scope
- Hoisting
- Closures
- `this`
- Prototypes
- Event Loop
- Promises
- Async/Await
- Performance Optimization
