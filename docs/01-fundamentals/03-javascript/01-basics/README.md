# Overview

Basics covers the core building blocks of JavaScript: what the language is, how you store values, how data is typed, and how you control program flow.

These four articles are the first segment of the [JavaScript React-Ready Path](../00-react-ready-path.md).

---

# Learning Objectives

After this module, you'll be able to:

- Explain what JavaScript is and where it runs.
- Declare variables with `let` and `const`.
- Recognize primitive and reference types.
- Use operators, conditionals, and loops confidently.
