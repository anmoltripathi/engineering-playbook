# Overview

This is the **minimum JavaScript path** you should complete before starting React.

You do not need the entire JavaScript curriculum to begin React. You need enough confidence with variables, functions, objects, arrays, modern ES6 syntax, and light DOM awareness so React concepts feel familiar instead of mysterious.

This React-Ready Path is the Phase B MVP for JavaScript in Engineering Playbook.

---

# Why This Matters

React is a JavaScript library. Skipping JavaScript fundamentals is one of the most common reasons beginners struggle with React.

If you can read and write modern JavaScript comfortably, React becomes a UI library problem—not a language problem.

---

# Learning Objectives

After completing this path, you'll be able to:

- Declare and update values with `let` and `const`.
- Work with primitives, objects, and arrays.
- Write functions (including arrow functions) and pass callbacks.
- Use essential ES6 features React depends on.
- Understand what the DOM is and why React abstracts it.
- Start [React Fundamentals](../../02-frontend/01-react/01-react-fundamentals/README.md) with confidence.
