# Overview

Functions package reusable logic. In React, components are functions (or historically classes), event handlers are functions, and hooks are functions. This module’s MVP article covers the essentials you need before React.

---

# Learning Objectives

- Declare functions in the common modern styles.
- Pass parameters and return values.
- Understand callbacks at an introductory level.
- Connect functions to how React components work later.
