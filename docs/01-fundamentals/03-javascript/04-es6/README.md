# Overview

ES6 (ECMAScript 2015) and later features are the default dialect of modern JavaScript. React tutorials assume template literals, destructuring, spread/rest, modules, optional chaining, and nullish coalescing.

---

# Learning Objectives

- Use the ES6 features React codebases rely on daily.
- Import and export modules at a high level.
- Write safer property access with `?.` and `??`.
