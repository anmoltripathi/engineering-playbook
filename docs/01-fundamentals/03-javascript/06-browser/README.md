# Overview

Browsers expose APIs for pages and documents. The most important for frontend engineers is the **DOM**. This MVP keeps coverage light: enough to understand what React manages for you.

---

# Learning Objectives

- Explain what the DOM is.
- Select and update elements at a basic level.
- Attach a simple event listener.
- Articulate why React abstracts direct DOM work.
