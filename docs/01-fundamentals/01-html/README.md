# HTML

> The foundation of every website.

---

# Overview

HTML (HyperText Markup Language) is the standard markup language used to structure content on the web.

Every web application, regardless of framework or programming language, begins with HTML.

Whether you're learning React, Angular, Vue, Next.js, or backend development, understanding HTML is essential.

---

# Learning Objectives

By the end of this module, you will be able to:

- Understand how HTML works
- Build semantic web pages
- Create accessible websites
- Develop SEO-friendly pages
- Create professional forms
- Organize page structure correctly
- Follow modern HTML best practices
