> Module: Fundamentals → HTML
>
> Version: 1.0

# Overview

This module covers HTML from beginner to professional level, including semantic markup, accessibility, SEO, forms, multimedia, and modern best practices.

---

# Learning Outcomes

After completing this module, learners will be able to:

- Understand how HTML works
- Build semantic web pages
- Create accessible websites
- Develop SEO-friendly pages
- Build production-ready forms
- Structure maintainable HTML documents
