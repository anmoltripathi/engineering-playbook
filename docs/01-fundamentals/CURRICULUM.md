# Fundamentals Curriculum

> **Stage 1 – Software Engineering Fundamentals**
>
> Version: 1.0

---

# Overview

The Fundamentals stage provides the essential knowledge required for modern web and software engineering.

Every advanced topic—whether React, Angular, FastAPI, System Design, or AI Engineering—builds upon these fundamentals.

This stage focuses on understanding the technologies that power the web rather than memorizing syntax.

---

# Learning Goals

After completing this stage, learners should be able to:

- Build semantic web pages
- Create responsive user interfaces
- Write modern JavaScript
- Use TypeScript confidently
- Understand browser internals
- Communicate with APIs
- Work professionally with Git
- Read official documentation
- Debug applications effectively
