# Fundamentals FAQ

## Why should I learn HTML before JavaScript?

Because JavaScript manipulates HTML and CSS. Understanding the document structure is essential before adding behavior.

---

## Can I skip CSS?

No. Modern frontend engineering requires a solid understanding of layout, responsiveness, and accessibility.

---

## Do I need TypeScript?

Yes. Most production frontend applications use TypeScript for better maintainability and developer experience.

---

## Should I learn Browser internals?

Yes. Understanding rendering, the event loop, networking, and storage helps you write performant applications and debug effectively.

---

## Why is Git included?

Version control is a core engineering skill. Every professional development workflow depends on Git.
