# Engineering Glossary

> **Version:** 1.0
>
> This glossary provides concise definitions of common software engineering terms used throughout the Engineering Playbook.
>
> Every technical article should reference these definitions instead of redefining common concepts.

---

# How to Use

- Definitions are intentionally concise.
- Every term links to a detailed article where applicable.
- Terms are listed alphabetically.
- Avoid duplicating definitions across articles.

---

# A

## API

**Application Programming Interface**

A contract that allows two software systems to communicate using predefined rules.

Related:

- HTTP
- REST
- GraphQL
- WebSocket

---

## Asynchronous Programming

A programming model where tasks can execute without blocking the main thread.

Related:

- Event Loop
- Promise
- Async/Await

---

## Authentication

The process of verifying a user's identity.

Examples:

- Password
- OTP
- OAuth
- JWT

---

## Authorization

Determines what an authenticated user is allowed to access.

Related:

- RBAC
- Permissions
- Roles

---

# B

## Browser

Software that downloads, renders, and executes web applications.

Examples:

- Chrome
- Firefox
- Safari
- Edge

---

## Bundler

A tool that combines application files into optimized bundles.

Examples:

- Vite
- Webpack
- Rollup
- Parcel

---

# C

## Cache

Temporary storage that improves performance by reducing repeated work.

Examples:

- Browser Cache
- Redis
- CDN Cache

---

## Callback

A function passed as an argument to another function.

Related:

- Promise
- Async/Await

---

## Closure

A function that remembers variables from its lexical scope even after the outer function has finished executing.

Related:

- Scope
- Lexical Environment
- Execution Context

---

## Component

A reusable piece of user interface.

Examples:

- React Component
- Angular Component

---

# D

## DOM

**Document Object Model**

A tree representation of an HTML document that JavaScript can manipulate.

---

# E

## Event Loop

The browser mechanism responsible for executing synchronous code and scheduling asynchronous tasks.

Related:

- Call Stack
- Microtask Queue
- Macrotask Queue

---

# F

## Framework

A collection of tools and conventions used to build applications.

Examples:

- React
- Angular
- Vue

---

# G

## Git

A distributed version control system.

---

## GitHub

A cloud platform for hosting Git repositories and enabling collaboration.

---

# H

## Hoisting

JavaScript behavior where declarations are processed before execution begins.

Related:

- Execution Context
- TDZ

---

## HTTP

HyperText Transfer Protocol.

The protocol used to transfer web resources between clients and servers.

---

# J

## JSON

JavaScript Object Notation.

A lightweight format for exchanging structured data.

---

## JWT

JSON Web Token.

A compact token format commonly used for authentication and authorization.

---

# L

## Lexical Scope

A rule determining variable accessibility based on where code is written.

---

# M

## Memoization

An optimization technique that stores previous results to avoid unnecessary recalculations.

---

## Middleware

Software that executes between receiving a request and sending a response.

---

# O

## Object

A collection of key-value pairs used to model data.

---

# P

## Promise

An object representing the eventual completion or failure of an asynchronous operation.

---

## Prototype

The mechanism JavaScript uses to support inheritance.

---

# R

## React

A JavaScript library for building user interfaces.

---

## REST

Representational State Transfer.

A widely adopted architectural style for web APIs.

---

# S

## Scope

Defines where variables can be accessed.

---

## SPA

Single Page Application.

A web application that dynamically updates a single HTML page.

---

## SSR

Server-Side Rendering.

Rendering HTML on the server before sending it to the browser.

---

# T

## TypeScript

A typed superset of JavaScript.

---

## TDZ

Temporal Dead Zone.

The period between entering a scope and the initialization of variables declared with `let` or `const`.

---

# V

## Virtual DOM

A lightweight representation of the DOM used by frameworks to optimize rendering.

---

# W

## WebSocket

A protocol enabling persistent, bidirectional communication between client and server.
