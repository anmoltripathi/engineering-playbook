# Learning Paths

> **Version:** 1.0
>
> The Frontend Engineering Playbook supports multiple learning journeys. Choose the path that best matches your goals.

---

# How to Use This Guide

Not every learner has the same destination.

Some want a frontend job.

Some want to become full-stack engineers.

Some want to crack interviews.

Some want to become software architects.

Each path recommends a different sequence of modules while sharing the same knowledge base.

---

# Path 1 — Beginner to Frontend Developer

**Who is this for?**

- Beginners
- Students
- Career starters
- Self-taught developers

### Learning Journey

```text
01 Fundamentals
│
├── HTML
├── CSS
├── JavaScript
├── TypeScript
├── Browser
├── HTTP
└── Git
        │
        ▼
02 Frontend
│
├── React
├── State Management
├── Routing
├── Forms
├── Accessibility
├── Performance
└── Projects
        │
        ▼
05 Testing
        │
        ▼
09 Career
```

### Estimated Duration

6–9 Months

### Final Skills

- Build production-ready frontend applications
- Work with APIs
- Use Git professionally
- Pass junior to mid-level frontend interviews

# Recommended Study Routine

## Part-Time Learners

- 1–2 hours/day
- 5 days/week
- Build one project per module
- Review weekly

- 6–8 hours/day

# Success Metrics

You are progressing well if you can:

- Explain concepts without memorizing
- Build projects independently
- Debug confidently
- Read official documentation
- Pass technical interviews
- Review others' code
- Mentor junior developers
